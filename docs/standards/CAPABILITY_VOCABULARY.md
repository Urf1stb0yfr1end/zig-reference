# Capability vocabulary

Canonical capability names are concise lower-case problem descriptions derived only from implemented or concretely planned module contracts. `generated/capability-ontology.json` records description, aliases, related and broader/narrower terms, negative matches, full and partial implementers, common queries, and mistaken matches. Aliases improve recall but never create a capability. Negative matches prevent lexical similarity from being mistaken for compatible guarantees. Edit module discovery metadata; do not hand-edit the generated ontology.
