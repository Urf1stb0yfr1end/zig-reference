# Capability vocabulary

Capabilities are lower-case, descriptive search concepts derived from implemented or accepted planned work. Each ontology record may name aliases, related/broader/narrower terms, negative matches, exact and partial implementers, expected input/output kinds, common questions, mistaken matches, planned consumers, and enabled milestones.

Prefer one canonical term and a small set of real user phrasings. An alias improves recall but is not semantic proof. Negative matches prevent close but incorrect selections. New terms require a canonical contract or accepted roadmap need; speculative taxonomy bloat and duplicate synonyms are rejected by consistency review. `generated/capability-ontology.json` is derived and never edited directly.
