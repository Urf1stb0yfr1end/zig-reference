# Module lifecycle

Lifecycle is intent, not evidence: `proposed`, `experimental`, `active`, `stable`, `deprecated`, `superseded`, or `archived`. Proposed work has no promised implementation. Experimental contracts may change. Active modules are maintained. Stable modules additionally require maturity level 9. Deprecated modules remain discoverable with migration guidance; superseded modules name a replacement; archived modules receive no routine maintenance. Generators reject unknown values and must not infer quality from lifecycle alone.
