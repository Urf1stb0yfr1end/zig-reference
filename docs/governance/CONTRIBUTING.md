# Contributing

Query `generated/` through `tools/query-reference.py` before proposing a mechanism. Read the selected `details.json`, human DETAILS, dependencies, then source/tests. Reuse compatible modules. Change canonical sources, regenerate textual views, consult `COMMANDS.md`, and run the strongest applicable checks under Zig 0.14.0.

A contribution explains ownership, borrowing, cleanup, invalidation, failures, compatibility, dependencies, security boundaries, and evidence. Never claim skipped validation, hand-edit generated views, add opaque artifacts, or silently change the Zig baseline. Breaking or policy changes require an RFC; normal compliant modules and bug fixes do not. Keep commits reviewable and report pending checks honestly.
