MISSION

Extend the proven Batch 11 freestanding RISC-V execution boundary by exactly one machine capability:

TAKE A REAL SYNCHRONOUS SUPERVISOR TRAP, CAPTURE A FIXED BOUNDED INTERRUPTED STATE, RETURN CORRECTLY WITH SRET, AND THEN CONTINUE INTO THE SAME SETTLED MORPHIC SEMANTICS.

Batch 11 proved:

→ RISC-V S-mode
→ explicit freestanding Zig entry + stack

→ exact canonical Morphic bytes

Batch 12 asks:

CAN OUR FREESTANDING S-MODE PAYLOAD ESTABLISH ITS OWN SUPERVISOR TRAP VECTOR, SURVIVE A DELIBERATE SYNCHRONOUS TRAP, PRESERVE THE INTERRUPTED EXECUTION STATE, RETURN TO THE CORRECT NEXT INSTRUCTION, AND STILL PRODUCE THE SAME CANONICAL MORPHIC RESULT?

→ our S-mode entry

Use standard terminology: TrapFrame / trap frame, register context, stvec, sepc, scause, stval, sstatus, sret.

The trap frame must be fixed-size and allocation-free.

PHASE 5 — IMPLEMENT REAL TRAP ENTRY AND RETURN

The target-specific path may perform only the machine work needed for this proof.

At minimum:

1. establish an aligned trap entry;
2. write stvec intentionally;
3. execute the deliberate trap probe;
4. enter through the hardware trap path;
5. capture the bounded trap frame before clobbering interrupted state;
6. expose the observed trap state to a tiny target-neutral or target-specific recorder as appropriate;
7. establish the resume PC according to the known probe instruction;
8. restore the interrupted register state;
9. execute sret;
10. prove execution continued after the trapped instruction.

For a deliberately emitted known 32-bit EBREAK probe, advancing sepc by 4 is acceptable only at that narrow probe boundary. Do not turn that into a universal exception-resume rule. Real future exceptions may require different policy or instruction-length handling.

Preserve the causal state before mutating sepc for return. The verifier/report should be able to distinguish observed fault PC from resume PC or resume delta.

If the trap handler cannot safely return, Batch 12 is not complete. Printing a trap and shutting down is useful partial evidence but does not satisfy the mission.


PHASE 6 — PROVE REGISTER PRESERVATION, NOT JUST CONTROL TRANSFER

A handler that reaches stvec but corrupts interrupted state is not a usable trap boundary.
