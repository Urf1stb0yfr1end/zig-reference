KNOWN MERGED LIMITATION — PRESERVE THE TRUTH
======================================================================

Main intentionally contains one documented namespace-resolution limitation from
Batch 32G.

The current bounded resolver follows a symlink when the complete pathname being
looked up is itself the symlink, but it does not yet resolve symlinks
component-by-component inside a longer pathname.

Example known gap:

  /usr/lib -> /lib
  /lib/example.so exists

  openat(AT_FDCWD, "/usr/lib/example.so", O_RDONLY)

may fail because the resolver first seeks the full manifest path rather than
walking components, resolving /usr/lib, appending the remaining suffix, and
continuing.
