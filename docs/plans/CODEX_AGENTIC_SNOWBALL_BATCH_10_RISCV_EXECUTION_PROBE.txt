PHASE 3 — CROSS-COMPILE EXISTING SEMANTICS FIRST

Before designing a RISC-V machine adapter, attempt the cheapest correct path:

Prefer a statically linked target if that avoids a guest dynamic loader. Discover Zig 0.14.0's actual target syntax rather than blindly copying target strings from this request.

- riscv_core.zig containing copied scheduler/resource/trace logic;

- separate RISC-V formatting semantics;
