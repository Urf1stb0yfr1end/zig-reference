PHASE 3 — PRESERVE SYNCHRONOUS EXCEPTION SEMANTICS

This phase is mandatory because Batch 13 introduces the first asynchronous trap class.

The trap path must distinguish at least:

SYNCHRONOUS BREAKPOINT
- scause interrupt bit = 0
- cause = breakpoint
- known 32-bit EBREAK probe
- resume policy may advance sepc by exactly the mechanically proven instruction width

ASYNCHRONOUS SUPERVISOR TIMER INTERRUPT
- scause interrupt bit = 1
- supervisor timer cause
- sepc represents interrupted execution state
- DO NOT blindly apply the breakpoint sepc + 4 rule

A generic "all traps advance sepc" implementation is a Batch 13 failure.

Preserve the Batch 12 ELF/runtime anchoring for the EBREAK proof.

If dispatch is refactored, prove that the old synchronous path still behaves exactly as before.


PHASE 4 — ESTABLISH THE SMALLEST REAL TIMER CONTRACT

Implement only what one bounded timer delivery requires.

existing freestanding S-mode payload
