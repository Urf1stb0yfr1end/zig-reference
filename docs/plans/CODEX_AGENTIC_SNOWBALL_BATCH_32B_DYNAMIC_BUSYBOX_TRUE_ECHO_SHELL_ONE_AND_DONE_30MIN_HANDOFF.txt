======================================================================

Morphic remains NOT the dynamic linker.

Correct boundary:

  exact dynamic BusyBox
      -> Morphic supplies executable + real interpreter + process facts
      -> real musl interpreter runs in U-mode
      -> userspace loader performs loader work
      -> BusyBox runs

Keep Linux conventions at the compatibility edge. Keep neutral mapping,
filesystem, process-start, resource, address-space and object mechanisms in

returns, hardcoded BusyBox addresses, direct-main entry, kernel-applied dynamic
relocations, precomputed output, weakened W+X, or speculative broad compatibility
work.
