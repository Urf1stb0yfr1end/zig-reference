MISSION

Advance the merged Batch 21A planner into the real freestanding RISC-V machine path by proving exactly one new architectural pressure:

real U-mode bytes
→ user pointer + length in registers
→ U-mode ECALL
→ trusted S-mode trap stack
→ adapt active Sv39 translation into bounded-user-memory-transfer-plan
→ validate the complete user range
→ copy exact bytes through resolved physical segments into trusted supervisor storage
→ mechanically prove the copied bytes
→ SRET back to U-mode
→ prove user execution resumed
→ terminal U-mode ECALL
→ known supervisor continuation
→ unchanged Morphic frame

This batch is COPY-IN only.

Do not implement copy-out in this run.
Do not build a syscall table.
Do not assign Linux syscall numbers.
Do not add a userspace ELF loader.
Do not add VFS, file descriptors, processes, mmap, brk, signals, futexes, threads, procfs, sockets, BusyBox, APK, or Alpine rootfs work.

The purpose is to turn the new reusable transfer planner into a real machine-proven safe user-read primitive without broadening the ABI surface.

BATCH 21B USER PROBE

Create a distinct relocation-safe ELF-visible copied user template.

Suggested symbols:

userCopyInProbeTemplateBegin
userCopyInProbeServiceEcall
userCopyInProbeAfterService
userCopyInProbeTerminalEcall
userCopyInProbeFail
userCopyInProbeTemplateEnd

Exact names may follow current repository style.

The verifier must derive service ECALL, post-service continuation, terminal ECALL, and template bounds from the built ELF rather than trusting emitted expected constants.

User sequence:

1. reserve a bounded stack-local area;
2. write the exact 16-byte payload into that U RW/NX memory;
3. set one or more guard/sentinel values elsewhere in the stack frame;
4. place payload VA in a0;
5. place payload length in a1;
6. optionally place a private Batch 21B operation marker in a2/a7 if the existing bounded state machine benefits from one;
7. execute the service ECALL;
8. after SRET, require the expected success/result marker;
9. verify user-side sentinels remain intact;
10. write a post-return marker proving resumed U-mode execution;
11. set a distinct terminal marker;
12. execute the terminal ECALL;
13. fail-stop if execution ever falls through unexpectedly.

No libc.
No heap.
No SBI from U-mode.
No Linux syscall numbers.
No privileged instruction in the copied user template.
No absolute kernel symbol embedded into relocated U code.

SUPERVISOR SERVICE

Keep a deliberately private Batch 21B state machine.

On the service trap, fail closed unless at minimum:

- interrupt bit is zero;
- scause is U-mode ECALL (8);
- trapped SPP=0;
- sepc equals the ELF-derived service ECALL VA;
- phase is exactly the expected Batch 21B service phase;
- a1 equals the exact bounded payload length;
- user pointer is accepted only through the planner path;
- trusted trap-stack/frame invariants hold.

Do not read payload bytes before the complete plan succeeds.

COPY THROUGH PHYSICAL SEGMENTS

After the complete read plan succeeds:

for each planner segment:

- use segment.physical_start;
- use segment.byte_count;
- use segment.request_offset;
- access the already supervisor-accessible physical/identity-mapped backing, not the original user VA;
- copy into one fixed supervisor-owned scratch array.

Suggested scratch bound:

32 bytes

Required actual copied length:

16 bytes

Initialize the entire scratch array with a poison byte before the copy, for example 0xA5.

After copy, mechanically prove:

- bytes [0..16) equal the exact payload;
- bytes [16..scratch.len) retain the poison value;
- observed copied length is exactly 16;
- segment coverage sums to exactly 16;
- no source user VA was directly dereferenced by the S-mode copy path.

A deterministic digest may be recorded in addition to exact bytes, but do not use only a digest when exact 16-byte equality is cheap.

SUM POLICY

Keep sstatus.SUM=0 throughout Batch 21B.

The point is to prove that user virtual pointers are treated as untrusted address descriptions, not as supervisor-dereferenceable pointers.

The verifier must inspect actual saved/prepared/trapped status evidence sufficient to prove SUM remained zero across the relevant supervisor path.

Do not merely print sum=0 as a hard-coded claim.

RETURN TO U-MODE

After successful copy and proof:

- set deterministic success marker in saved a0 or another documented return register;
- advance/prepare sepc to the ELF-derived userCopyInProbeAfterService continuation;
- prepare sstatus for U-mode return with SPP=0 and safe expected interrupt/SUM policy;
- restore user integer context;
- rearm sscratch so the next U→S trap again swaps onto the trusted supervisor trap stack;
- execute SRET.

User code must then mutate a post-return marker before the terminal ECALL so the second trap proves the first SRET actually resumed U-mode instructions.

TERMINAL TRAP

The second Batch 21B U-mode ECALL is terminal for this sub-batch.

Fail closed unless:

- cause=8;
- interrupt=0;
- SPP=0;
- sepc equals the independently ELF-derived terminal ECALL VA;
- post-return user marker is present in real saved user state;
- terminal marker is present in real saved user state;
- exact expected trap count/phase is observed;
- trusted trap-stack invariant is again satisfied.

Then deliberately establish the known S-mode continuation using the actual CSR/SRET path consistent with Batch 20's proven architecture.

Do not leave cosmetic frame.sepc/frame.sstatus edits that are not applied.
