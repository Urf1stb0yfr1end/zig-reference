======================================================================

Morphic is NOT the dynamic linker.

Correct boundary:

  dynamic main ELF
      -> Morphic maps main + interpreter and builds correct process facts
      -> real musl interpreter executes in U-mode
      -> musl resolves/maps/relocates its userspace image
      -> main executes

Keep Linux ABI conventions at the compatibility edge.
Keep neutral mapping, filesystem, process-start, resource and address-space
mechanisms at the Morphic center.

No artifact-name checks, no hardcoded musl addresses, no symbol-name patches,
no direct-main-entry bypass.
