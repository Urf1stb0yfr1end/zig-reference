# Integration contract

Import `morphic-semantic-operation`. Construct `Request.read_bytes` or `Request.write_bytes` with a complete `ResourceId { slot, generation }`, a `GuestAddress`, and `byte_count`, or construct `Request.terminate`. The resource slot is not an OS descriptor; the generation distinguishes successive resources that reuse bounded storage. `execute` synchronously borrows a caller-owned backend and returns `Completion.success`, `.failure`, or `.terminated`. There is no allocation, global state, retained borrow, OS ABI, or architecture ABI. The backend owns full-identity resource resolution, whole-range validation, transfer effects, and termination effects.
