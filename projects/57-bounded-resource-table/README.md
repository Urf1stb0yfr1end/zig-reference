# Bounded resource table

A fixed-capacity, allocation-free Morphic resource substrate. `ResourceTable` composes project 08 generational handles with reference counts and operation capabilities; `BindingTable` provides deterministic process-local aliases. Neither API contains Linux descriptors, errno, syscall numbers, register names, QuirkM ABI, or Wasm ABI.

See [DETAILS.md](DETAILS.md), [MASTERY.md](MASTERY.md), and [port.js](port.js).
